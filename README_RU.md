# Local Screen Analyzer — тестовый проект

Это исходный проект Android Studio, а не готовый APK. В этой среде нет Android SDK/Gradle, поэтому я не могу честно сказать, что собрал и проверил APK.

## Что делает прототип
- Показывает список приложений, установленных на телефоне.
- По нажатию запускает системное разрешение Android на захват экрана.
- После разрешения запускает foreground-сервис, который получает кадры локально и сразу освобождает их.
- Не отправляет экран в интернет, не сохраняет кадры, не управляет игрой и пока НЕ распознаёт объекты.

## Как собрать APK на компьютере
1. Установи Android Studio.
2. Распакуй ZIP.
3. Открой папку `LocalScreenAnalyzer` через **Open**.
4. Дождись синхронизации Gradle.
5. Если Android Studio попросит установить SDK 35, согласись.
6. Выбери **Build → Build APK(s)**.
7. APK обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.

Минимум: Android 8.0; ориентировано на Android 13+. На Android 13 разреши уведомления, если появится запрос.

## Важное
Список приложений — только выбор для удобства; Android MediaProjection захватывает экран согласно системному диалогу, а не получает скрытый доступ к выбранной игре. Защищённые экраны могут быть чёрными. Следующий этап для распознавания объектов — добавить совместимую локальную TFLite-модель и постобработку; без модели ИИ-распознавания в этом проекте нет.


## Облачная сборка APK без установки Android SDK на компьютере
В проект добавлен workflow GitHub Actions. Чтобы собрать APK в облаке:
1. Создай новый репозиторий на GitHub.
2. Загрузи в него содержимое этой папки (именно файлы проекта, не ZIP как единственный файл).
3. Открой вкладку **Actions** и разреши запуск workflows, если GitHub спросит.
4. Выбери **Build Android APK** → **Run workflow** (или отправь файлы в ветку `main`, чтобы сборка запустилась автоматически).
5. После завершения открой успешный запуск и внизу раздел **Artifacts**.
6. Скачай `LocalScreenAnalyzer-debug-apk.zip`, распакуй его и установи `app-debug.apk` на телефон.

Это не мгновенная готовая сборка: GitHub выполнит сборку в облаке, и если возникнет ошибка, её лог можно прислать для исправления.
